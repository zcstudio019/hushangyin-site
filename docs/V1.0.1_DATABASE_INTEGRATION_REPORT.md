## 8. 现存安全风险

- 便携二进制是第三方打包的本地开发工具，无OpenSSL支持，仅绑定环回。不能直接把它作为生产数据库方案；生产应使用受维护的PostgreSQL部署、TLS、受控网络和备份加密。
- 本地凭据文件包含开发用明文随机凭据，已Git忽略并限制NTFS权限；没有声称实现KMS字段加密或安全凭据托管。不得复制这些凭据到生产或共享日志。
- 当前应用角色拥有本项目数据库以便本地迁移，生产应分离迁移账户与低权限运行账户。
- 默认来源限流桶共享；生产若使用可信代理，必须覆盖来源头后再开启TRUST_PROXY，不能直接信任客户端头。
- 隐私主体、真实联系方式、权利渠道、留存策略和加密/备份机制尚未具备生产条件。本地测试声明不替代生产隐私公示。
