## 1. 实际原因

### 导航与权限

源码 `src/app/admin/(protected)/geo/layout.tsx` 原本已有 `/admin/geo/generation/` 链接，文字为“人工智能创作”，使用 `can(actor, "generation.create")` 隐藏。路由、任务API、Provider和独立Worker均已实现，不是缺少整个AI模块。

修改前实际浏览器使用原本地超级管理员登录3000服务，能看到该链接并进入工作台。原构建时间2026-10-31 15:30，晚于导航源码修改时间；启动器及Next.js属于本项目，没有证据表明该地址运行旧静态网站。初查只有一组本项目平台启动器/Next服务，Worker未运行。

原有3个有效账号分别为超级管理员、独立内容审核员、融资顾问，均已完成首次改密。超级管理员拥有 generation.create / generation.manage；独立审核员仅有 content.read / content.review，不能创作。聊天无法读取用户浏览器原会话，不能断言用户当时登录了哪个账号；但所述仅有五项GEO菜单的表现与独立审核岗位完全一致，已用独立审核测试账号复现。此次没有修改现有账号角色、密码或增加其权限。

实际UX缺口是：创作入口名称与预期不一致、权限隐藏没有解释；问题列表也确实没有“生成文章”操作，工作台不接受预选问题参数。现已分别修复。

### FAQ自动关联

数据库当前有1条已发布、8条已审核、51条待审核FAQ。9条已审核/发布内容均没有外部网址，采用现有风险分级专业判断审核；旧AI检索仍调用 `currentFaqSources` 强制每条存在外部来源，因此合格通用FAQ也被全部过滤。

现复用 `risk-v1` 的专业判断记录及 `recheckFaqRisk`：没有具体高风险主张、具有当前版本独立审核记录、完整综合确认及专业判断的通用知识可检索。仍排除待审核版本、来源失效内容、高风险无依据内容和需要受控内部证据的知识；不发送审核人的私有判断原文或内部资料。执行前和入库前都会再次检查。

## 8. 尚未完成及使用说明

本次生成只是可编辑草稿，不是已核验金融内容。通用FAQ的专业判断不替代文章所需的外部事实依据，当前外部参考资料目录为空；原文章合规检查仍提示补充有效来源和具体段落，不能直接跳过审核发布。用户应补充真实可核验依据，由不同的独立审核人阅读全文后，再由授权发布人发布。本次没有替用户作这项金融事实审核或公开发布。

网关单价、账单准确性和幂等计费保证未验证，报告用量仅来自供应商响应。真实任务本轮只调用1次，没有尝试其他模型。当前Next.js与Worker均已本地启动；停启按原 npm start / npm run worker:geo 流程，不部署生产。

如果仍看不到入口，请核对登录岗位：超级管理员或内容运营可以创作；独立审核员默认不兼任作者。需调整岗位时由超级管理员经现有员工管理和近期身份核验流程授权，本次不擅自改变现有员工角色。
