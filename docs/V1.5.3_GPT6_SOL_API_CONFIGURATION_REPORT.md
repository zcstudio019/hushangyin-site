## 4. 请求及结果适配

- 复用 HttpAiProvider，新增 openai-compatible 别名，保留原 Responses 和 compatible-chat。
- 发送指定 model、messages、reasoning_effort、max_completion_tokens，不发送 temperature 或 top_p，不自动切换模型。
- 生成默认使用结构化 JSON Schema，提取其中 Markdown、摘要、SEO、依据及关联，再经现有 Zod、安全和来源校验保存文章草稿；不自动发布。
- 支持文本字符串或文本块响应，拒绝空结果、拒答、截断、非法 JSON 和返回模型不一致；不将 reasoning_content 当正文。
- 安全区分认证失败、模型不可用、额度不足、限流、参数不兼容、超时及网关异常；不显示原始上游错误或请求正文。
- 有返回值时保留 Token 用量；配置可靠单价后才估算成本。未知用量/费用保留未知，不伪造数值。

**兼容性边界：尚无有效密钥，无法确定网关是否支持此模型、reasoning_effort、max_completion_tokens、store:false 或 json_schema。** 当前参数是明确的待验证配置，不是已确认的供应商契约。若返回不支持参数，应根据网关真实文档明确修改 AI_CHAT_TOKEN_PARAMETER 或 AI_CHAT_RESPONSE_FORMAT，再重新测试；程序不会擅自降级或更换模型。公开网关首页未提供足以验证该模型的接口契约。

## 5. 连接检测与权限

入口：http://127.0.0.1:3000/admin/geo/generation/ 。页面显示服务商、模型、API地址、是否配置密钥及最近测试结果。超级管理员/具有 generation.manage 权限者勾选费用确认后点击“测试模型连接”。每次完成后确认框清空，重新测试需再次确认。

检测只发送固定短指令，不发送问题、FAQ、文章或客户资料，输出预算256，最长30秒，不自动重试，不创建文章。每人每15分钟最多3次，全局最多10次，需同源CSRF及服务端权限验证。近期结果复用现有审计表持久化，配置变化后不会误用旧配置结果。

接口：

| 方法和路径 | 行为/权限 |
| --- | --- |
| GET /api/admin/geo/generation/connection/ | generation.create，读取非敏感状态 |
| POST /api/admin/geo/generation/connection/ | generation.manage，同源，confirmedCost:true，执行一次检测 |

无密钥时立即返回 `connected:false, code:KEY_MISSING`，提示“尚未配置 API 密钥”，不发起上游请求。诊断接口HTTP200表示诊断完成，**不代表模型连接成功**；应读取 connected。未登录401、跨源403、未确认费用400、运营测试403均已实际验证。

## 6. Worker、重试与资料保护

任务仍存原 PostgreSQL 表，Worker 使用原锁/租约与唯一文章关联。任务快照绑定非敏感模型配置签名，配置变化后旧任务不能悄悄换模型或网关执行；失败记录和已知Token用量保留。

自定义网关只有明确429限流可有限自动重试。超时、网络中断、5xx、租约过期等费用不确定情形不自动重新调用。手工重试或重新生成已有调用任务时，必须逐次确认可能重复计费；相同输入发送稳定 Idempotency-Key，但网关是否支持尚未验证，**不能承诺计费恰好一次**。文章侧仍防止并发重复入库。

生成仅使用问题选题、符合既有审核条件的FAQ/已发布文章及批准的通用参考资料。受控内部银行资料目录排除，不读取客户数据库作为提示词。补充文本拦截手机号、证件/卡号、客户标识、密钥、原始征信/流水等特征；新增全角和零宽字符归一检查。自动规则无法代替人工资料审查，操作者不得粘贴客户财务原文。AI输出继续进入现有草稿、独立人工审核、授权发布流程。
