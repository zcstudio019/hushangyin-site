## 1. 原项目分析

沿用 Next.js App Router、TypeScript、Prisma 6、PostgreSQL、iron-session、Argon2id、Zod 与原 RBAC。复用 articles、article_versions、content_reviews、审核工作流、Markdown 编辑器、安全渲染、动态 Sitemap 和公开 `/insights/` 路由；`/knowledge/` 兼容跳转保持。

审计时数据库为100道融资问题、60组FAQ、4篇原文章、2个账号、2条原线索、1个部门。60组FAQ均为待审核，不能作为确定事实输入。既有4篇迁移文章没有可据以补造的新审核记录，只作历史选题背景；不虚构核验日期。原项目没有模型密钥、AI Provider 或持久化生成执行器。

指定完整主题“企业有利润却缺现金流，应该先融资还是先改善回款？”在原库没有完全相同文字。浏览器使用原题“现金流紧张时先融资还是先改善回款？”（问题ID `cmvtav1aw003kt1lo29zujtvn`）验证选题和检索，未改写原题。隔离数据库另用明确标记的合成问题验证队列逻辑。

## 2. 已开发功能

### 创作工作台与模板

- `/admin/geo/generation/`：搜索问题，展示分类、关键词、意图、状态；选择7种文章类型、模板版本、读者、3种深度及最多4000字补充资料。
- 展示原始问题、相似问题、已审核问答、已发布文章、人工核验参考资料及缺少依据的提示。
- 默认模板包含标题、核心问题、直接回答、适用对象、关键因素、准备步骤、常见错误、相关问答、风险提示、咨询引导、参考资料11部分。
- 结果预览复用安全 Markdown 渲染，显示任务状态、待核实事项、用量和可获得的估算成本，进入原文章编辑页继续处理。
- `/admin/geo/generation/templates/`：超级管理员维护版本化模板及人工核验参考资料；不自动访问来源网址，也不自动确认其金融真实性。
- 无密钥时明确显示缺失配置，生成按钮禁用，服务端同样返回503，不创建虚假草稿。

### 知识检索与内容安全

PostgreSQL 原生全文检索、分类、关键词和中文包含匹配，无新增向量数据库或搜索服务。问答必须有匹配版本的人工通过记录，来源日期有效，且为当前已审核版本或已发布快照。兼容原导入问答的版本号0，不能误把0当成不存在。待审核内容不进入事实知识列表。检索接口保留可替换适配层。

单次检索有数量上限；生成输入快照最多128KB。生成前和保存前重新检查知识及来源是否变更。模型输出采用严格结构化 JSON 校验，关联问题和FAQ须属于检索白名单，引用只能来自已核验目录，引用段落须实际出现于正文，不能编造外部网址。疑似手机号、身份证号、银行卡号、邮箱、姓名字段以及不安全网页代码会被拦截；这些规则不能代替人工判断。

### 草稿、事实检查与审核

生成成功在同一事务中写入原 articles 草稿、article_versions、问题/FAQ关联、引用段落、模型/模板溯源、用量与任务结果；只在事务提交成功后标记任务完成。没有第二套编辑器或发布系统。

规则结果分为“必须修复”“需要人工核实”“优化建议”，检查保证放款承诺、银行关系、利率额度、政策、案例、不当建议、还款风险、关键词重复、来源段落及FAQ审核资格。仅实际生成溯源文章强制执行这些新增关卡，原人工文章的原审核流程保持兼容。

“必须修复”阻止提交审核、审核通过及发布。即使规则无阻断，也必须由另一位授权人员勾选原金融核验清单、填写说明并审核；发布仍独立验证 RBAC 与当前版本审批记录。AI自评不提供发布许可。来源在同一天被重新核验或修改摘录，也会使旧草稿的来源绑定失效，需要重新保存版本并审核。

生成文章在原编辑器中使用分组引用字段，保留多行段落、列表与表格分隔符；原人工文章逐行来源输入仍兼容。新增可选搜索标题、搜索描述，发布快照用于公开 Metadata。公开页面展示来源标题、网址、核验日期、对应段落和风险/咨询引导。未发布文章不公开。

### 问题状态回写

问题与文章为多对多关系，保留原单篇 articleId 兼容字段。草稿建立关联后问题可为已规划；正式发布后变为已解答。下线重新检查该问题的全部关联文章，只要仍有线上解答就保持已解答，否则回到已规划。原题文字、来源及历史关联保留；归档问题不被自动重新启用。编辑线上文章的草稿不使原公开快照失效。

## 5. AI Provider 接入方式

仅服务端使用环境配置，支持 Responses 严格结构输出与兼容 Chat 接口；无新增大型SDK。模型必须显式配置，不设置默认模型。`AI_GENERATION_ENABLED`、`AI_EXTERNAL_TRANSMISSION_APPROVED`、密钥与模型全部满足才允许创建任务。每次创建还需用户确认资料非敏感。密钥不进入页面、任务快照、审计或报告。

限制5至120秒超时、1000至16000输出词元；远程响应最多1MB。拒绝重定向，供应商错误正文不外显。限流/服务端临时失败由任务有限重试；认证错误、无效结构和不安全内容不盲目重试。记录供应商、模型、尝试、状态、可用请求ID和词元用量；配置有效单价且返回用量才估算美元成本，否则显示不可估算，不填虚构成本。没有真实供应商用量或账单可供核对。

协议实现参考 [OpenAI严格结构化输出官方指南](https://developers.openai.com/api/docs/guides/structured-outputs)。协议单元验证不等于实际模型兼容验收；供应商认证、模型可用性、中文效果和计费均待获准接入后验证。

## 6. 异步任务机制

独立 `npm run worker:geo`，与网站分开运行。任务生命周期：待执行、生成中、已完成、失败、已取消。PostgreSQL `FOR UPDATE SKIP LOCKED` 领取任务，租约令牌和时间持久化；执行最多3次，有限退避。执行器重启后回收过期租约。单请求幂等、同创建人活跃请求去重、每任务唯一输出以及保存前状态/租约校验共同防止重复文章和取消后的迟到写入。

创建、执行前、保存前均检查相关权限/账号状态；管理员重试他人的任务仍使用原创建人的可信会话版本及去重范围。执行期间轮询取消信号，模型超时可中止。数据库故障时保存事务回滚，后续租约恢复，不假装成功。当前本地执行器已实际启动并验证数据库心跳，验证后停止；网站服务继续运行。真实供应商请求的超时重试可能产生额外费用，不能保证供应商侧恰好调用一次。

## 7. API 与权限

统一基础地址 `/api/admin/geo/generation/`，GET不缓存，写请求校验同源和请求体大小。

| 方法/参数 | 功能 | 权限 |
|---|---|---|
| GET（默认，含q） | 问题、可用模板、配置缺失及执行器状态 | generation.create |
| GET view=knowledge&questionId=… | 审核知识与参考资料检索 | generation.create |
| POST | 创建持久化任务，返回任务标识 | generation.create |
| GET view=tasks&page=… | 授权范围内分页列表 | generation.create |
| GET view=task&id=… | 状态、结果、用量和尝试日志 | 本人或generation.manage |
| PATCH action=cancel/retry/regenerate | 取消、有限重试、创建新草稿任务 | 本人或generation.manage |
| PATCH action=save | 返回已原子保存的文章ID，不重复创建 | 本人或generation.manage |
| PUT kind=template | 新增/修改模板并递增版本 | generation.manage |
| PUT kind=reference | 保存人工核验资料、核验人和时间 | generation.manage |

内容运营仅新增 `generation.create`，无审核/发布/模板管理权限；超级管理员有 `generation.manage` 和原审核发布权限；销售主管、融资顾问无生成权限。原客户端数据范围规则不变。未登录401、无权限403，他人任务按404处理。每人每小时最多5次新生成，原内容写入限流继续有效；请求体32KB、设置维护64KB。审计记录创建、取消、重试、模板版本、资料核验和草稿保存，不写模型密钥或提示词全文。
