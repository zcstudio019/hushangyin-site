## 2. 已开发功能

### 内容仪表盘

实际统计文章总数、线上文章、待审核文章、草稿、未归档融资问题、FAQ；展示最近发布内容和文章/FAQ审核待办。线上版本与改稿状态分开计数，同一文章可能同时在线并有待审改稿。不展示未接入的流量、AI推荐或收录数据。

### 融资问题库

人工新增、编辑、归档、搜索筛选、优先级1—5、关键词、四种搜索意图、关联文章和问题状态。内置任务要求的10类融资主题，另保留历史“融资知识”分类。已解答问题必须有关联文章。

支持CSV文件读取或粘贴导入：UTF-8/BOM、引号、逗号、换行和转义引号；文件64KB、最多100行；整批校验并在事务内保存，重复或异常内容不留下部分导入。文件不保存到public或服务器磁盘。问题采用归档，未开放物理删除。

### 文章与FAQ

文章包含标题、永久slug、摘要、Markdown正文、分类、标签、引用、相关文章、AI辅助标记、作者/最后编辑人、状态、时间及历史版本；后台列表搜索、筛选、25条分页。FAQ包含问题、答案、分类、引用、关联文章及同样的审核发布流程。FAQ在关联的已发布文章内展示，不单独开放公开草稿接口。

编辑器提供H2/H3、段落、有序/无序列表、表格、引用、图片引用和内外链接工具；标题字段生成唯一H1。正文里的一级标题语法按H2展示，避免重复H1。原始HTML按普通文字处理，不执行脚本或事件属性。图片仅支持已审核的本地PNG/JPEG/WebP/GIF引用；上传保持禁用，没有新增图片上传API。

### 审核、发布与版本

草稿 → 待审核 → 已审核 → 已发布 → 已下线；支持退回修改和撤回审核。

- 服务端按真实权限检查动作，并在数据库锁内再次检查账号有效性、会话版本和最新权限。
- 编辑和工作流操作带revision，拒绝旧页面覆盖新内容；待审内容锁定编辑，需先撤回。
- 审核人必须不同于该版本最后编辑人。内容运营无审核和发布权限；超级管理员编辑的稿件同样需要另一位有审核权限的人员。
- 审核需要至少10字说明和7项确认：引用/数据/适用时间、审批放款承诺、银行关系、案例、误导宣传、客户隐私及人工阅读全文（包括AI辅助内容）。
- 审核与发布都校验至少一项HTTPS引用、合法核验日期及有效截止日期。程序只检查结构和时间，来源的真实性与金融表述必须由真实人工核验，不能把任意HTTPS地址当作事实背书。
- 保存已发布文章的改稿时生成新草稿，线上仍读取上一次发布快照；只有新版本审核通过并发布，才替换公开内容。
- 每次文章保存、退回、撤回和恢复均保留版本。恢复历史内容生成新草稿，不直接恢复发布状态，必须重新审核。已公开的slug下线后仍不可改写。
- 发布、下线、审核、恢复及问题操作写入审计；不记录密码、Cookie或客户手机号。

### 公开知识与咨询衔接

公开知识页从数据库读取线上快照，服务端输出HTML；每篇文章有Title、Description、Canonical、Article JSON-LD及可信的作者/发布时间/更新时间。未知的历史作者和原发布日期不补造。引用、相关知识文章、已发布FAQ及合规咨询CTA可见；未发布文章404，预览需要认证。FAQ采用适用语义及FAQPage标记，不保证搜索引擎展示富媒体结果。

Sitemap采用动态路由，下一次请求自动反映发布/下线，无需重新构建。文章列表和Sitemap的数据库查询排除全文/历史HTML，避免逐篇读取完整正文。动态配置依据 [Next.js Sitemap约定](https://nextjs.org/docs/app/api-reference/file-conventions/metadata/sitemap)。

CTA只将非敏感文章ID带入咨询页。原POST `/api/consultations/`验证文章仍在线，并在原线索/授权事务中存入sourceArticleId、规范化sourcePage、允许的来源标记及原有createdAt。只允许utm_source/utm_medium/utm_campaign，每项最多40位ASCII字母数字及 `_.-`，拒绝手机号样式值和未知字段；不将手机号、征信或银行资料写入URL。来源标记属于用户可影响的营销上下文，不是身份或不可伪造的归因证明。

## 6. API 清单

所有内容API都在既有 `/api/admin/` 下鉴权，写操作同源校验、JSON大小限制、Zod严格字段校验和持久化限流（每账号内容写100次/15分钟）；权限拒绝与发布等操作按原审计体系记录。

| 方法 / 路径 | 功能 |
| --- | --- |
| GET `/api/admin/geo/{kind}/?q=&category=&status=&page=` | 25条分页、搜索和筛选 |
| POST `/api/admin/geo/{kind}/` | 新建问题/文章/FAQ；201 |
| GET `/api/admin/geo/{kind}/{id}/` | 认证读取编辑内容、作者、审核和版本信息 |
| PATCH `/api/admin/geo/{kind}/{id}/` | 严格字段及revision校验后保存；问题通过status归档 |
| POST `/api/admin/geo/{kind}/{id}/workflow/` | submit/approve/reject/publish/offline/withdraw/restore；逐动作检查权限与状态 |
| POST `/api/admin/geo/questions/import/` | CSV文本原子导入；201 |
| POST `/api/consultations/` | 原接口；可选sourceArticleId/sourceParameters，原事务保存授权和来源 |

公开文章仅由公开页面读取已发布快照；未提供公开获取草稿、历史版本、审核记录的API。预览和后台接口未登录401或跳转登录，角色禁止403，公开未发布/下线文章404。没有图片上传或物理删除内容API。
