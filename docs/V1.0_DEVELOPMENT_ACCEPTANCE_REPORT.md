## 1. 原项目技术分析

原项目为 Python 标准库生成的原生 HTML/CSS/JavaScript 静态多页站，无 package.json、前端框架、数据库或部署脚本。Phase 1 读取了全部15份HTML、Python模板、公共配置、CSS/JS、表单、SEO、sitemap、robots和README；审计见 `PHASE-1-AUDIT.md`、`legacy-audit.json`。

原有15页：`/`、`/about/`、`/enterprise/`、`/personal/`、`/products/`、`/precheck/`、`/cases/`、`/insights/`、`/risks/`、`/contact/`、`/privacy/`，以及 `/insights/enterprise-loan-guide/`、`/insights/cash-flow-vs-profit/`、`/insights/credit-report-check/`、`/insights/mortgage-business-loan/`。

可复用品牌Logo、深蓝金色、Hero与金融装饰、产品/案例/知识文章正文、响应式CSS和产品筛选。原咨询表单仅演示，预审只做本地文件检查；旧SEO域名仍为example.com。旧导航 `{name}` 根因是Python普通字符串未插值，前次任务已修复，本次迁为React数据映射，不再依赖该模板。

修改前备份37个文件至 `backups/pre-v1-20261028.zip`。全部15份原HTML保持字节哈希一致；未删旧页面，旧站仍可在8080端口预览。README标明旧脚本只属于历史静态站，避免误覆盖新平台。

## 2. 最终架构设计

同目录模块化单体：Next.js 16.4.3 App Router、React19.3.1、TypeScript5.9.3、Tailwind4.3.3、PostgreSQL/Prisma6.19.3、Zod4.6.7。npm与package-lock锁定依赖。身份认证使用iron-session9加密Cookie、数据库可撤销会话及Argon2id2.2.2密码哈希库。

- 官网：`src/app/(website)`，受控本地正文服务端输出；旧路径原样保留，没有改为 `/knowledge/`。
- 布局：共享React Header/Footer/Logo；`src/config/site.ts` 为当前平台唯一菜单、品牌、CTA与Footer配置。
- 内容：`src/features/content` 保留旧正文、元数据、文章参考来源。原始HTML仅作为受控本地资产使用，绝不把客户输入当HTML渲染。咨询页、隐私页和上传提示因真实处理边界调整。
- 样式：`src/app/brand.css` 维护当前品牌CSS；Tailwind仅增加带 `tw:` 前缀的工具类，不启用preflight，以免与原 `.outline` 等类冲突。
- 业务：`src/features/leads` 处理事务咨询和后台受权读写；`src/lib` 提供DB、会话、请求保护、验证。
- 数据：一套PostgreSQL；Prisma Schema及版本化初始SQL迁移，无微服务、无AI调用、无文件接收模块。

Phase 1审计备份 → Phase 2原站渐进迁移 → Phase 3 Schema/迁移SQL → Phase 4真实咨询API与表单 → Phase 5后台和权限 → Phase 6 GEO → Phase 7构建/回归/文档。缺少数据库的阶段只确认代码与Schema，不将其标为运行验收通过。

## 4. 数据库表结构

| 表 | 主要字段与关系 | 索引/约束 |
|---|---|---|
| customers | id、name、phone、customerType、可选companyName、createdAt/updatedAt | id主键，phone索引 |
| leads | id、可选customerId、name、phone、customerType、financingAmount、可选hasProperty/hasCompany/remark、source/sourcePage、status、可选assignedTo、时间戳 | 客户/管理员外键；状态+时间、分配人+时间、phone/customerId/updatedAt索引 |
| admin_users | id、name、email、passwordHash、role、isActive、时间戳 | email唯一；密码仅Argon2id哈希 |
| audit_logs | id、可选actorId、action、resourceType、可选resourceId/metadata、createdAt | 管理员外键；操作者+时间、资源、时间索引；不记录手机号/备注 |
| consents | id、可选leadId/customerId、consentType、policyVersion、agreedAt、evidenceReference | 关联外键、唯一凭证引用、关联/时间索引 |
| articles | id、title、slug、summary、content、category、status、可选publishedAt、时间戳 | slug唯一，状态+发布时间索引 |
| faqs | id、question、answer、category、status、时间戳 | question唯一，状态+类别索引 |
| loan_products | id、name、category、targetCustomer、description、requirements(JSON)、status、时间戳 | name唯一，状态+类别索引 |
| admin_sessions | id、tokenHash、adminId、expiresAt、createdAt | tokenHash唯一、管理员外键、到期索引 |
| rate_limit_buckets | key(HMAC来源/账户)、count、expiresAt | key主键、到期索引，跨进程原子限频 |
| submission_guards | key(HMAC指纹)、expiresAt | key主键、到期索引，事务内防重复 |

金额沿用原表单档位字符串；布尔可空代表未填写。客户档案不因同电话自动合并，避免错误关联。客户/线索关联删除SetNull，审计/授权不随身份记录误级联删除。会话随管理员删除级联清除。

迁移为新增表/索引/外键，不包含DROP/TRUNCATE/业务DELETE。Prisma生成的SQL与再次生成结果一致；**这不等于已在PostgreSQL执行迁移**。`prisma migrate deploy` 管理重复部署，禁止直接重复执行原始SQL或使用生产reset。

未转化线索建议最后更新180天后由负责人复核删除/匿名化；授权、审计及客户档案最终留存期限需按真实业务公示，不自动清空。数据库TLS、磁盘及备份加密是部署条件，本机未配置/验证；应用当前没有字段级KMS加密。

## 5. API清单

所有接口返回 `{ok:true,data}` 或 `{ok:false,error:{code,message}}`，错误不暴露数据库细节；API禁止缓存和索引。尾斜杠由Next规范化，原 `/api/consultations` POST保留方法跳转到规范路径。

| 方法与路径 | 功能 | 保护 |
|---|---|---|
| POST /api/consultations/ | 保存咨询线索及对应授权记录 | Zod、手机号/长度/同意、8KB流式体积限制、Origin、10次/15分钟来源限频、5分钟防重复、数据库事务 |
| POST /api/admin/login/ | 验证管理员、建立会话并审计 | 2KB、Origin、邮箱/来源双限频、Argon2id、通用失败提示 |
| POST /api/admin/logout/ | 删除服务端会话、清Cookie、审计 | 服务端登录验证、Origin |
| GET /api/admin/leads/ | 脱敏列表、25条分页 | 服务端会话、角色/分配范围、读取审计 |
| GET /api/admin/leads/[id]/ | 详情及授权 | 服务端会话、行级访问范围、读取审计 |
| PATCH /api/admin/leads/[id]/ | 修改五种线索状态 | 登录、行级访问、Origin、1KB/Zod、更新与审计同事务 |

后台页面 `/admin/`、`/admin/login/`、`/admin/dashboard/`、`/admin/leads/`、`/admin/leads/[id]/`。布局及数据页面分别验证会话，不能仅靠客户端跳转保护。ADMIN可访问全部，AGENT仅分配给自身的记录；无权详情返回404避免泄露存在性。

- 预审文件选择禁用，无文件上传API、public存储或第三方AI发送。
- 首次管理员私有环境初始化、可重复文章草稿初始化、运行/部署/留存/备份/回滚文档。
