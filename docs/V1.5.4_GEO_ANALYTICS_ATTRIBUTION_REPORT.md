## 4. 事件采集与去重

- 仅统计已公开的文章详情/FAQ详情；预览、草稿、下线、后台和列表不计。
- 默认不采集，不先写分析Cookie或随机标识。用户主动同意后签发30分钟凭证，当前窗口sessionStorage保存短期随机标记；可停止或拒绝，不影响咨询。
- 不使用客户姓名、手机号、IP、完整User-Agent、完整Referrer或设备指纹作为分析身份。服务器仅查看已知机器人User-Agent特征，不保存该字段；共享/可信代理请求桶使用既有HMAC限速机制。
- 事件ID与去重键唯一；重试同一事件不累加；另以日×内容×匿名会话去重访问，日×内容×匿名会话最多一次转化。
- 事件、去重保护和日聚合在数据库事务中完成；转换计数随咨询事务提交。客户端成功提示不构成统计依据。
- 同源校验、5KB请求上限、严格字段与公开内容校验、凭证签名/时效、事件120次/分钟/请求桶、来源60次/分钟/请求桶、授权30次/分钟/请求桶。
- 这不是机器人完全识别或自然人识别系统：可控浏览器/伪造请求仍可能形成异常样本，不能将匿名标记认定真实客户，生产仍需结合可信代理限速与异常监控。

## 5. 咨询归因规则

1. 文章/FAQ咨询点击先请求来源接口，服务端核验已发布内容及同源Referer路径，再签发最多30分钟的内容上下文。
2. 提交到原 `/api/consultations/` 后再次核验内容，以服务器读取的ID、公开标题和路径保存归因，不能提交任意文章名称作为可信来源。
3. 线索、咨询授权、归因和可选转化计数使用同一原有Prisma事务；任何失败回滚，不创建第二套线索系统。
4. 支持来源文章ID或FAQ ID，二者分别统计，不将FAQ自动算成文章。过期或验签失败的凭证归为未知，格式非法请求被拒绝，直接访问归为直接访问/来源未知，不强行计为GEO。
5. 无签名的旧文章/FAQ参数仅校验内容真实且公开，标记 `VALIDATED_LEGACY`；签名同源上下文为 `SIGNED_CONTEXT`。二者均不是客户身份或外部渠道真实性证明。
6. UTM只接收source/medium/campaign三个40字符以内营销代码，限制格式并拒绝明显手机号/凭据模式；不允许客户资料进入来源URL。渠道是客户端提示，可能伪造，不能反推AI引用或平台推荐。
7. 采用最后一次内容点击的短窗口来源，不做跨设备或长期首次触达追踪。匿名标记按上海日期脱敏，跨午夜不拼接访问，因此跨日的分析转化可能低估，但真实咨询及其内容来源仍会保存。必要咨询来源与可选访问统计分开；拒绝分析时仍可记录本次咨询的必要内容来源，但不计入匿名访问转化率。

## 6. 指标口径

| 指标 | 计算与限制 |
| --- | --- |
| 已发布文章/FAQ | 当前数据库公开状态，不受7/30/90日筛选影响 |
| PV | 用户同意后的有效公开内容浏览事件，重试事件ID只一次 |
| 去重访问 | 上海日期×内容×30分钟窗口随机会话；不是自然人UV |
| 咨询点击 | 授权样本中有效的公开内容咨询点击事件 |
| 成功咨询/归因线索 | 原咨询事务成功写入的线索及有效内容归因，不依赖浏览器回调 |
| 访问到咨询转化率 | 已成功咨询至少一次的授权匿名访问÷授权匿名访问，30分钟归因窗口，归到来源PV日；同一访问多次咨询只一个转化 |
| 渠道 | 可疑但可用于分析的UTM/Referrer主机提示，明确显示“来源线索” |
| 搜索曝光/平台点击 | 仅实际取得的CSV/API数据，绝不使用网站PV替代 |
| AI提及/引用/推荐 | 目前仅人工经核验抽样，三者分开，不自动计算全平台排名 |

无有效采集数据显示“暂无数据”；已有样本但点击为0时才展示实测0。小于20次匿名访问标记低样本，排序不优先夸大转化率。转化率不是点击率，也不是全量咨询数/PV。分类筛选是文章分类，未筛选总览包含FAQ访问。历史线索不猜测、不回填归因。
